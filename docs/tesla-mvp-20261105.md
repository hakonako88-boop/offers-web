## Auditoría y arquitectura

Repositorio existente React 19 / vinext / Vite, exportación estática a GitHub Pages. `app/api/deals` y las tablas Drizzle de `db/schema.ts` no constituyen un CMS con escritura autenticada disponible en Pages. Las ofertas existentes vienen de JSON y procesos independientes. No se modifican esos procesos ni se insertan accesorios pendientes en el canal.

Arquitectura implementada:

- `/tesla/`: selector, compatibilidad por variante, comparador, contenido de compra y Telegram.
- `/tesla/guias/model-3/` y `/tesla/guias/model-y/`: dos guías originales. Highland y Juniper se tratan dentro de sus guías, no mediante combinaciones automáticas de año y acabado.
- `/tesla/gestion/`: editor de JSON en el navegador, importación, validación y descarga. **No es un CMS conectado**, no escribe al servidor y no tiene secretos. No introducir credenciales ni datos privados.
- `data/tesla-catalogue.json`: fuente editorial ampliable; importa los diez enlaces del propietario intactos.
- `scripts/tesla-catalogue.mjs`: validación, compatibilidad y comparación compartidas por web y pruebas.

Todas las rutas nuevas tienen `noindex` y no se añaden al sitemap ni a la portada durante revisión. Los cambios están solamente en local; no se hace commit/push/despliegue sin aprobación. La exportación está preparada para las cuatro rutas.

## Resultado real de los diez enlaces

La herramienta web no pudo abrir los enlaces cortos. Una segunda comprobación HTTP directa siguió sus redirecciones con éxito (200); diez IDs distintos guardados. Se conserva el enlace corto original como referencia de compra; la URL canónica se puede reconstruir solo para identificar el producto, no para reemplazar la afiliación.

No se extrajo contenido de las fichas, ni se sorteó ningún bloqueo. No hay credenciales autorizadas de AliExpress cargadas en el entorno local. No se han comprobado título, marca, fotos, SKU, variantes, stock, precios ni atribución efectiva de comisión. Por tanto, `products` y `vehicleConfigurations` quedan vacíos. Resolver una URL no confirma esos hechos.

La API existente `resolveAliExpressAffiliateProduct` puede servir como adaptador futuro, pero su respuesta de detalle de producto **no certifica por sí sola todas las variantes ni compatibilidades**. No se llama a generación de enlaces sobre las referencias originales del propietario. No se ha habilitado actualización automática ni publicación Telegram.

## Contrato de datos

Producto: `id`, `name`, `category` (categoría admitida), `variants`.

Cada variante: `id` global único, `name`, `imageUrl` (solo imagen permitida), `identityKey` (marca + referencia + tamaño + material + cantidad), `differences`, `compatibilities`, `offers`.

Regla de compatibilidad: `status` (`confirmed`, `pending`, `unknown`), `model`, `generation`, `market`, `yearBasis` (`manufacture`/`model`), `years` explícitos, `trimPolicy` (`specific`/`not_relevant`), `trims` cuando sea relevante y `evidence`.

Cada evidencia: `url` HTTPS, `note` explicando qué acredita y `checkedAt` ISO. La regla no se confirma a partir de un título “Model Y”. La política `not_relevant` requiere también evidencia; no es un comodín para evitar revisar acabados.

Configuraciones de vehículo: registros separados `model`, `generation`, `year`, `yearBasis`, `market`, `trim`, `evidence`. Solo esos acabados documentados se ofrecen en el selector; nunca una lista universal Standard/Premium/Long Range/Performance. El año introducido por el visitante no constituye evidencia. Selección guardada únicamente mediante botón en localStorage; recuperarla no evita una nueva evaluación.

Oferta por variante: `store`, `originalUrl`, `affiliateUrl`, `affiliateConfirmed`, `identityKey`, `identityEvidence`, `price`, `shipping`, `taxIncluded`, `currency`, `market`, `status`, `checkedAt`, `evidence`, `conditions`.

Comparación: misma identidad documentada, EUR/España, IVA incluido, envío numérico conocido, disponible, fecha no futura y <=24 h, afiliación confirmada. Promociones condicionadas se excluyen del ahorro universal. Total redondeado a céntimos. Ahorro solo con >=2 tiendas distintas; no se usa un PVP ficticio. Un intervalo actualiza la vista cada minuto para retirar precios caducados. No se emite marcado Product/Offer para datos no comprobados.

## Flujo manual seguro

1. Abrir `/tesla/gestion/` en la vista previa.
2. Importar o editar el JSON. Mantener los diez enlaces originales intactos.
3. Añadir únicamente variantes identificadas con evidencias. Datos desconocidos no equivalen a cero ni envío gratis.
4. Validar y descargar borrador. Esto no actualiza el archivo del repositorio.
5. Revisar el archivo y ejecutar pruebas antes de incorporar cambios mediante un cambio de código revisado.
6. Pedir aprobación de despliegue. Solo después publicar, enlazar desde la web, retirar noindex donde proceda y añadir al sitemap.
